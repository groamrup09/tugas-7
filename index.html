🎯 Pengantar Generic

Apa itu Generic? Fitur untuk membuat kode yang bekerja dengan berbagai tipe data.

Analog: Kotak penyimpanan yang bisa menampung apa saja, tapi dengan label tipe.

📌 Manfaat Generic:
✅ Type safety (keamanan tipe)
✅ Code reusability (penggunaan ulang)
✅ Compile-time checking

⚠️ Masalah Tanpa Generic

❌ Kode Bermasalah

📝 Sintaks Generic Dasar

Type parameter: <T>, <E>, <K, V>
Konvensi:
• T = Type
• E = Element (collection)
• K = Key, V = Value
• R = Return type
✅ Contoh Benar
// Nama: Azriel Miracle Yuandre
// NIM: 251410024
// KELAS: SI2A         
class MyClass<T> {
  T data;
  MyClass(this.data);
  T getData() => data;
}

T myFunc<T>(T value) => value;

void main() {
  // Class generic
  var myIntClass = MyClass<int>(10);
  var myStringClass = MyClass<String>("test");
  print(myIntClass.getData());   // Output: 10
  print(myStringClass.getData()); // Output: test

  // Fungsi generic
  var intValue = myFunc<int>(100);
  var stringValue = myFunc<String>("hello");
  print(intValue);   // Output: 100
  print(stringValue); // Output: hello
}

📦 Kelas Box<T>

✅ Contoh Implementasi
// Nama: Azriel Miracle Yuandre
// NIM: 251410024
// KELAS: SI2A         
class Box<T> {
  T? _value;
  Box(this._value);
  T? get value => _value;
  void setValue(T value) { _value = value; }
}

void main() {
  // Box dengan tipe int
  var intBox = Box<int>(10);
  print('Int Box: ${intBox.value}'); // Output: Int Box: 10
  intBox.setValue(20);
  print('After set: ${intBox.value}'); // Output: After set: 20

  // Box dengan tipe String
  var stringBox = Box<String>("Hello, Generic!");
  print('String Box: ${stringBox.value}'); // Output: String Box: Hello, Generic!
  stringBox.setValue('Hello World');
  print('After set: ${stringBox.value}'); // Output: After set: Hello World

  // Box dengan tipe double
  var doubleBox = Box<double>(3.14);
  print('Double Box: ${doubleBox.value}'); // Output: Double Box: 3.14
}

🔑 Kelas Pair<K, V> (Multi Type Parameters)

✅ Contoh Benar
class Pair<K, V> {
  K key;
  V value;
  Pair(this.key, this.value);
  void printPair() => print('Key: $key, Value: $value');
}

void main() {
  // Pair String-int
  var pair1 = Pair<String, int>('age', 30);
  pair1.printPair(); // Output: Key: age, Value: 30

  // Pair String-String
  var pair2 = Pair<String, String>('name', 'Alice');
  pair2.printPair(); // Output: Key: name, Value: Alice

  // Pair int-double
  var pair3 = Pair<int, double>(1, 2.71);
  pair3.printPair(); // Output: Key: 1, Value: 2.71
}

⚙️ Fungsi Generic combine<T, U>

✅ Contoh Benar
String combine<T, U>(T value1, U value2) {
  return '$value1, $value2';
}

void main() {
  var result1 = combine<String, int>("Number is ", 10);
  print(result1); // Output: Number is , 10

  var result2 = combine<int, double>(10, 20.5);
  print(result2); // Output: 10, 20.5
}
❌ Contoh ERROR
// ❌ ERROR: Tipe tidak kompatibel dengan fungsi
/*
var result3 = combine<int, String>(10, 20);
// Bisa, tapi kurang tepat karena U seharusnya String tapi diisi int
*/

🔒 Generic dengan Extends (Constraints)

📌 Keyword extends → membatasi tipe data yang dapat digunakan.
✅ Contoh Benar
class NumberBox<T extends num> {
  T value;
  NumberBox(this.value);
  T getValue() => value;
}

void main() {
  // ✅ Valid - int dan double adalah turunan num
  var intBox = NumberBox<int>(10);
  print("int box: ${intBox.getValue()}"); // Output: int box: 10

  var doubleBox = NumberBox<double>(3.14);
  print("double box: ${doubleBox.getValue()}"); // Output: double box: 3.14
}
❌ Contoh ERROR
// ❌ ERROR: String bukan turunan dari num
/*
var stringBox = NumberBox<String>("test");
// ERROR: The type 'String' is not a subtype of 'num'
*/

🔍 Type Inference (Inferensi Tipe)

✅ Contoh Benar
T myFunc<T>(T value) => value;

void main() {
  // Dart menginferensi T secara otomatis
  var intValue = myFunc(10);
  print(intValue.runtimeType); // Output: int

  var stringValue = myFunc("test");
  print(stringValue.runtimeType); // Output: String

  var doubleValue = myFunc(3.14);
  print(doubleValue.runtimeType); // Output: double
}

📚 Generic dengan Interface/Class

✅ Contoh Benar
void printIterable<T extends Iterable<dynamic>>(T iterable) {
  for (var item in iterable) {
    print(item);
  }
}

void main() {
  printIterable<List<int>>([1, 2, 3]);
  // Output: 1, 2, 3

  printIterable<Set<String>>({'apple', 'banana'});
  // Output: apple, banana
}
❌ Contoh ERROR
// ❌ ERROR: int bukan turunan dari Iterable
/*
printIterable<int>(10);
// ERROR: The type 'int' is not a subtype of 'Iterable<dynamic>'
*/

📊 Generic vs Dynamic vs Object

Aspect Generic <T> dynamic Object
Type Safety ✅ Compile-time ❌ Runtime ✅ Compile-time
Flexibility Terbatas (sesuai T) Sangat fleksibel Terbatas
Performance ✅ Optimal ❌ Overhead ✅ Optimal
Casting Tidak perlu Tidak perlu Perlu casting
Contoh Perbedaan
Box<int> box1 = Box<int>(42); // Generic: aman

dynamic box2 = 42;   // Dynamic: tidak aman, bisa diubah jadi String

Object box3 = 42;    // Object: perlu casting
int value = box3 as int;

🗄️ Studi Kasus: Class Cache<T>

✅ Implementasi Cache Generic
class Cache<T> {
  final Map<String, T> _storage = {};

  void set(String key, T value) {
    _storage[key] = value;
  }

  T? get(String key) {
    return _storage[key];
  }

  void remove(String key) {
    _storage.remove(key);
  }

  void printAll() {
    _storage.forEach((key, value) => print('$key: $value'));
  }
}

void main() {
  // Cache untuk String
  var userCache = Cache<String>();
  userCache.set('name', 'Alice');
  userCache.set('email', 'alice@example.com');
  print('Name: ${userCache.get('name')}'); // Output: Name: Alice
  userCache.printAll();

  // Cache untuk int
  var numberCache = Cache<int>();
  numberCache.set('age', 25);
  print('Age: ${numberCache.get('age')}'); // Output: Age: 25
}

📝 Latihan Soal

💻 Soal 1: Buat class Repository<T> dengan method: save(T item), T getById(int id), List<T> getAll()
✅ Jawaban
class Repository<T> {
  final Map<int, T> _data = {};
  int _nextId = 1;

  void save(T item) {
    _data[_nextId++] = item;
    print('Saved: $item');
  }

  T? getById(int id) {
    return _data[id];
  }

  List<T> getAll() {
    return _data.values.toList();
  }

  void printAll() {
    _data.forEach((id, item) => print('ID $id: $item'));
  }
}

void main() {
  var userRepo = Repository<String>();
  userRepo.save("Alice");
  userRepo.save("Bob");
  print("User ID 1: ${userRepo.getById(1)}");
  print("All users: ${userRepo.getAll()}");
}
💻 Soal 2: Fungsi generic swap<T>(List<T> list, int i, int j)
✅ Jawaban
void swap<T>(List<T> list, int i, int j) {
  if (i == j) return;
  T temp = list[i];
  list[i] = list[j];
  list[j] = temp;
}

void main() {
  var numbers = [1, 2, 3, 4, 5];
  print("Before swap: $numbers");
  swap<int>(numbers, 1, 3);
  print("After swap: $numbers"); // Output: [1, 4, 3, 2, 5]
}
💻 Soal 3: Class Triple<A, B, C> dengan 3 field
✅ Jawaban
class Triple<A, B, C> {
  A first;
  B second;
  C third;

  Triple(this.first, this.second, this.third);

  void printTriple() {
    print('($first, $second, $third)');
  }
}

void main() {
  var triple1 = Triple<String, int, bool>("Alice", 25, true);
  triple1.printTriple(); // Output: (Alice, 25, true)

  var triple2 = Triple<int, double, String>(1, 3.14, "Pi");
  triple2.printTriple(); // Output: (1, 3.14, Pi)
}

🏆 Challenge: Sistem Repository Generic

✅ Solusi
class Product {
  final int id;
  final String name;
  final double price;
  Product(this.id, this.name, this.price);
  @override
  String toString() => 'Product($id, $name, $price)';
}

class User {
  final int id;
  final String username;
  User(this.id, this.username);
  @override
  String toString() => 'User($id, $username)';
}

class GenericRepository<T> {
  final Map<int, T> _items = {};
  int _nextId = 1;

  T? create(T item) {
    _items[_nextId] = item;
    return item;
  }

  T? read(int id) {
    return _items[id];
  }

  T? update(int id, T item) {
    if (_items.containsKey(id)) {
      _items[id] = item;
      return item;
    }
    return null;
  }

  bool delete(int id) {
    return _items.remove(id) != null;
  }

  List<T> readAll() {
    return _items.values.toList();
  }

  void printAll() {
    _items.forEach((id, item) => print('ID $id: $item'));
  }
}

void main() {
  var productRepo = GenericRepository<Product>();
  productRepo.create(Product(1, 'Laptop', 15000000));
  productRepo.create(Product(2, 'Mouse', 250000));
  print('Products: ${productRepo.readAll()}');

  var userRepo = GenericRepository<User>();
  userRepo.create(User(1, 'alice'));
  userRepo.create(User(2, 'bob'));
  print('Users: ${userRepo.readAll()}');
}

📖 Ringkasan

🎯 Poin Penting:
1. Generic membuat kode type-safe dan reusable
2. Bisa digunakan di class, fungsi, collections
3. Type inference memudahkan penggunaan
4. Constraints (extends) membatasi tipe yang diperbolehkan
📌 Best Practice:
• Gunakan generic untuk menghindari dynamic
• Gunakan extends untuk membatasi tipe
• Manfaatkan type inference untuk kode lebih bersih
